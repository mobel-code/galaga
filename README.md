# 🚀 GALAXY INVADERS — ARCADE SPACE SHOOTER

Современный аркадный космический шутер в стиле легендарной **Galaga (1981)** с неоновой sci-fi графикой, процедурным аудио синтезатором на Web Audio API, системой бесконечных волн, боссами и эффектами частиц.

---

## 🎮 Особенности игры

- **Аутентичный аркадный геймплей:** Плавное движение и стрельба, синхронное покачивание формаций, пикирующие атаки по криволинейным траекториям Безье и возврат противников в строй.
- **5 уникальных типов врагов:**
  1. 🛸 **Scout (50 очков):** Быстрый маневренный корабль с низким здоровьем.
  2. 🟡 **Fighter (100 очков):** Средний истребитель, стреляющий лазерами в игрока.
  3. 🔴 **Hunter (150 очков):** Пикирует на игрока по гладким траекториям с упреждением.
  4. 🟣 **Elite (300 очков):** Тяжёлый бронированный корабль (3 HP) с двойными орудиями.
  5. 👾 **Boss — Mothership Dreadnought (2000 очков):** Гигантский флагман с динамической полоской здоровья, 3 фазами боя, круговыми и прицельными залпами, и таранящими атаками (появляется каждую 10-ю волну).
- **Система оружия (4 уровня прокачки):**
  - **Level 1 — Basic Laser:** Одиночный скоростной лазер.
  - **Level 2 — Double Laser:** Спаренные параллельные пушки.
  - **Level 3 — Triple Shot:** Веерный залп под углами.
  - **Level 4 — Plasma Cannon:** Мощный плазменный шар повышенного урона + бортовые лазеры.
- **Бонусы (Power-Ups):**
  - ❤️ **Extra Life:** Дополнительная жизнь (до 5).
  - 🛡️ **Shield:** Защитное силовое поле на 10 секунд.
  - ⚡ **Rapid Fire:** Удвоенная скорострельность на 12 секунд.
  - 🔫 **Weapon Upgrade:** Повышение уровня вооружения.
  - 💥 **Smart Bomb:** Атомная волна, сметающая всех рядовых врагов на экране!
- **Процедурный ретро-аудио движок (Web Audio API):**
  - 100% процедурный Synthwave саундтрек (басовая линия, электронные барабаны, арпеджио).
  - Уникальная тревожная тема при сражении с боссом.
  - Синтезированные звуковые эффекты лазеров, взрывов, щита, бомбы и подбора бонусов без необходимости загружать внешние аудиофайлы.
- **Полная адаптация (Desktop + Mobile):**
  - **Компьютер:** Стрелки / A / D для движения, SPACE для стрельбы, ESC для паузы, ENTER для старта.
  - **Телефон / Планшет:** Управление пальцем (drag & drop с вертикальным смещением, чтобы палец не заслонял корабль), авто-стрельба, экранная кнопка паузы.
  - Автоматическое масштабирование игрового поля с сохранением пропорций (`Phaser.Scale.FIT`).
- **Интерфейс и настройки:**
  - Стильное главное меню с летающими кораблями и неоновым логотипом.
  - Модальное окно настроек (включение/громкость музыки и звуков, полноэкранный режим, качество графики).
  - Таблица рекордов (Hall of Fame) с сохранением в `LocalStorage`.
  - Минималистичный HUD (Счёт, Рекорд, Жизни, Волна, полоса здоровья Босса).
  - Экран Game Over с подробной статистикой точности и результатов.

---

## 🛠️ Стек технологий

- **Язык:** TypeScript
- **Игровой движок:** Phaser 3 (HTML5 Canvas / WebGL)
- **Сборщик:** Vite
- **Стилизация:** Vanilla CSS3 (Custom Sci-Fi Dark Theme)
- **Звук:** Web Audio API (Synthesizer & Sequencer)
- **Хранение данных:** LocalStorage API

## 🚀 Запуск проекта

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск в режиме разработки

```bash
npm run dev
```

После запуска откройте в браузере адрес, указанный в терминале (обычно `http://localhost:3000` или `http://localhost:3002`).

### 3. Сборка для продакшена

```bash
npm run build
```

Готовые статические файлы будут скомпилированы в папку `dist/`.

│   │   ├── HUD.ts               # Игровой интерфейс (счёт, жизни, волна, HP босса)

│   ├── styles/
